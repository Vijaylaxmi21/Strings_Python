# 🐍 Python String Practice

**A collection of simple Python programs to understand and practice string operations.**

---

## 📌 About This Repository

This repository contains Python programs based on strings, one of the most useful concepts in Python programming. Each program focuses on a specific operation and helps build a better understanding of how strings work.

## 📚 Topics Covered

| No. | Program | Concept |
|:---:|---|---|
| 01 | Reverse a String | String Slicing |
| 02 | Palindrome Checker | String Comparison |
| 03 | Count Vowels | Loops & Conditions |
| 04 | Count Words | `split()` & `len()` |


## 🛠️ Technologies Used

- **Language:** Python
- **Concepts:** Strings, Loops, Conditions, String Methods
- **Editor:** VS Code / Bytexl Editor

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Run any Python file using:

   ```bash
   python filename.py
   ```

4. Enter the required input and check the output.
